# Analyzing Sales Data Using Machine Learning
# Project Overview

This project focuses on analyzing sales data to uncover meaningful business insights such as sales trends, revenue performance, top products, and regional growth.
The goal is to support data-driven decision making using Python-based data analysis techniques.

# Dataset Description

The dataset contains historical sales records with the following attributes:
Order ID
Order Date
Product Name
Category
Quantity
Price
Revenue
Region
